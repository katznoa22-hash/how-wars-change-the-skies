# Project Planning and Initial AI Collaboration

## AI Tool
ChatGPT

## Project Title
How Wars Change the Skies

## Project Objective
Develop an interactive educational HTML presentation exploring how geopolitical conflicts affect commercial aviation, airspace restrictions, flight routes, travel times, and airline operations.

## Initial Planning Decisions
- The presentation and project documentation will be in English.
- The project will contain approximately 10 slides.
- JavaScript will provide navigation and interactive features.
- Python will be used for aviation-related calculations and analysis.
- Three.js will be used to create an animated 3D visualization.
- Historical examples and clearly labeled hypothetical scenarios will be used.

## Next Steps
Develop and review the Product Requirements Document (PRD) before implementation.
